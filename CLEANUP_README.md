## PLN-RAG Design Summary

PLN-RAG is a proof-based retrieval-augmented reasoning system:

```
Text → Chunker → Mention Prepass → LangExtract → PLN Postprocessor
                                                        ↓
                         ┌──────────────────────────────┼──────────────┐
                         ↓                              ↓              ↓
              SQLite Evidence Ledger          Qdrant Vector DB    PeTTaChainer
                         ↓                              ↓              ↓
Question → Evidence Retrieval → Query Alignment → Proof Search → Answer Generator
```

### Architecture

- **Storage Layer**: SQLite (authoritative), Qdrant (rebuildable index), PeTTaChainer (atomspace)
- **Extraction**: LangExtract parser converts natural language to PLN atoms
- **Reasoning**: PeTTaChainer proof engine with configurable timeout/steps
- **Quality**: Dynamic predicate mapping, deterministic validation, coreference resolution
- **Safety**: Strict proof validation, evidence traceability, lineage tracking

### Key Components

| Component | Path | Purpose |
|-----------|------|---------|
| API | `api/main.py` | FastAPI routes: ingest, query, reset, rebuild |
| Parser | `parsers/langextract_pln_parser.py` | NL → LangExtract → canonical PLN |
| Orchestration | `core/orchestration/service.py` | Pipeline orchestration |
| Reasoning | `core/reasoning/reasoner.py` | PeTTaChainer proof execution |
| Evidence | `storage/evidence_ledger.py` | SQLite persistence + lineage |
| Vector Store | `storage/vector_store.py` | Qdrant adapter for hybrid retrieval |
